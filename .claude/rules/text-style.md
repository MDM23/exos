# Text style

Applies to all generated text: docs, comments, commit messages, chat replies.

- Never use em-dash characters (`—`). Rephrase, or use commas, colons,
  parentheses, or a plain hyphen instead.
- No emojis, except where they carry real meaning instead of decoration, such
  as red or green bubbles (🔴 / 🟢) to signal state in status output or UIs.
